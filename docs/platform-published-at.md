# 每个平台的发布时间

同一期作品在各平台的发表时间可能不同。本变更在 tasks 增加 published_at 与 published_title，启动时检查旧库列定义后补列；重复启动不重复迁移。setTask 的普通状态更新保留已记录的时间和标题。

hub sync 将平台回读时间规范为北京时间，写入任务、工程 publish.json 和数据库快照。支持秒/毫秒时间戳、中文日期、带时区的 ISO 字符串；没有有效时间时保留原值。

单期页显示每家平台的发布时间。整期 publishAt 优先取主平台中最早有效时间，只有视频号时采用视频号；仅有扩展平台时取扩展平台。跳过的平台不参与定位，未回读到时间时前端沿用排期。

封面 coverVer 根据文件修改时间与大小生成；日历、档案和单期页使用该版本号，替换同名封面后可刷新缓存。

验证：node --test test/published-at.test.mjs，覆盖旧库迁移、重复加载、状态更新保留元信息及时间格式转换。可在单期页回读后核对平台时间、工程快照，再替换同名封面确认 URL 的版本号更新。
