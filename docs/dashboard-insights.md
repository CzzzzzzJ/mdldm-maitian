# 大屏首页数据概览

首页围绕当前作品显示播放、互动、互动率、最近三天可用快照差值、平台构成、每日累计量、发布后累计曲线与上期同龄比较。粉丝走势改为分平台堆叠面积，长标题根据实际文字宽度滚动。

仅有一个快照时不声称存在增长；没有采样的日期区分发布前与缺数据；累计曲线不足四个采样点时提示继续积累。图表只统计当前启用平台。overview 的每日数据查询补齐互动字段，不新增数据库表或采集任务。

本分支可独立合并：未提供 publishAt 时回退到 schedule 或 createdAt。保留 main 的平台管理、集成卡片、登录状态与 config.disabled 过滤。
